# Security and content policy (archived repository)

This project is closed and does not accept game binaries, console
firmware, proprietary SDKs, keys, copyrighted game assets, shader dumps,
memory dumps, decryption tools, links to unauthorized game downloads, or
unredacted private logs.

The remaining probes are local diagnostics. They use public Windows
APIs and do not load game files or require commercial game executables.

Do not post personal file-system paths, serial numbers, credentials,
tokens, private reports, or copyrighted materials in issues.

The project is **not maintained**, and no security response time is
promised. Refer to README.md and PROJECT_CLOSED.md for its status.
